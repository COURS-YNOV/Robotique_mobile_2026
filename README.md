# Projet Robot — Robotique mobile 2k26

## Barème d'évaluation (20 points)

| Critère | Points |
|---|---|
| Respect du cahier des charges (CDC) | 2 |
| Châssis fonctionnel et intégration cohérente des capteurs et actionneurs | 3 |
| Qualité du logiciel (architecture organisée, séparation drivers/boucle principale, modularité) | 5 |
| Analyse fonctionnelle | 2 |
| Tests en conditions réelles lors de la démonstration finale | 2 |
| Qualité de conception du robot (mécanique, électronique, intégration globale) | 4 |
| Utilisation de GitHub (branches, gestion des versions, suivi du développement) | 2 |
| **Total** | **20** |

### Détail des critères

1. **Respect du CDC** *(2 pts)*
   Le robot répond aux exigences fonctionnelles et techniques définies dans le cahier des charges.

2. **Châssis et intégration** *(3 pts)*
   Le châssis est fonctionnel et l'intégration des capteurs/actionneurs est cohérente avec l'ensemble du système.

3. **Qualité du logiciel** *(5 pts)*
   L'évaluation portera principalement sur la structure du code, avec notamment :
   - une architecture logicielle organisée ;
   - une séparation claire entre les drivers matériels et la boucle principale ;

4. **Analyse fonctionnelle** *(2 pts)*
   Pertinence et clarté de l'analyse fonctionnelle du système.

5. **Tests en conditions réelles** *(2 pts)*
   Comportement du robot lors de la démonstration finale.

6. **Qualité de conception** *(4 pts)*
   Mécanique, électronique et intégration globale du robot.

7. **Utilisation de GitHub** *(2 pts)*
   Usage des branches, gestion des versions et suivi du développement du projet.
